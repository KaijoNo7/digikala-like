# Azar Digital (آذر دیجیتال) — Persian Digital Store (Prototype)

A Persian (RTL) online store demo for digital products: phones, tablets, laptops, smartwatches,
audio, accessories and gaming. It has a React + Vite frontend and a small FastAPI backend, 31 products
with real photos, category pages with filters and sorting, and detailed product pages.

**Demonstration only:** no real checkout, payments or secure authentication. The brands are fictional.

## Run it

| OS | Backend (port 8000) | Frontend (port 5173) |
|---|---|---|
| Windows | `start-backend.bat` | `start-frontend.bat` |
| macOS | `start-backend.command` | `start-frontend.command` |
| macOS / Linux | `./start-backend.sh` | `./start-frontend.sh` |

Open <http://localhost:5173>. Demo login: `admin` / `admin`.
Requirements: Python 3.9+, Node.js 20.19+ or 22.12+.
