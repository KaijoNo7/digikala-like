# 07 — Backend API

The backend is one file, `backend/main.py`, a FastAPI application served by Uvicorn on port 8000.

```
backend/
├── main.py            the app
├── products.json      the catalog (generated by `npm run sync-products`)
└── requirements.txt   fastapi==0.120.4, uvicorn==0.54.0
```

Interactive docs are generated by FastAPI automatically:
- Swagger UI: <http://localhost:8000/docs>
- ReDoc: <http://localhost:8000/redoc>

## Endpoints

### `GET /api/health`
Liveness check.

```json
{ "status": "ok", "service": "azar-digital-demo-api", "products": 31 }
```

### `GET /api/products`
The full catalog. The frontend calls this on startup.

```json
{
  "count": 31,
  "products": [
    {
      "id": "mb-nova-x12",
      "enName": "Nova X12 Pro",
      "name": "گوشی موبایل نووا X12 پرو",
      "brand": "نووا",
      "category": "mobile",
      "price": 38900000,
      "oldPrice": 42500000,
      "image": "/img/products/mb-nova-x12.jpg",
      "stock": "in_stock",
      "rating": 4.6,
      "reviews": 1284,
      "warranty": "۱۸ ماه گارانتی",
      "description": "…",
      "features": ["…"],
      "specs": [["صفحه نمایش", "۶٫۷ اینچ AMOLED"], ["…", "…"]]
    }
  ]
}
```

The field meanings are in [06 — Data & catalog](06-data-and-catalog.md#3-product-schema). `image` paths
are relative to the **frontend** origin, because the photos are served by the frontend, not the API.

### `GET /api/products/{product_id}`
A single product.

- `200` → the product object (same shape as above)
- `404` → `{ "detail": "محصول پیدا نشد." }`

```bash
curl http://localhost:8000/api/products/au-anc-headphone
```

### `POST /api/login`
Checks the demo credentials.

Request body:
```json
{ "username": "admin", "password": "admin" }
```

- `200` → `{ "ok": true, "username": "admin" }`
- `401` → `{ "detail": "نام کاربری یا رمز عبور اشتباه است." }`
- `422` → validation error if a field is missing (standard FastAPI format)

**Not real authentication:** no password hashing, no token, no session. The frontend keeps the username
in React state only, so it is gone after a reload. The password is never stored in the browser.

## CORS

```python
allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"]
allow_methods=["GET", "POST"]
allow_headers=["Content-Type"]
```

If you serve the frontend from another port or domain, add that origin here.

## Data loading

`PRODUCTS` is read from `products.json` once, when the module is imported. After changing the catalog:

```bash
cd frontend && npm run sync-products     # regenerate backend/products.json
# then restart the backend (Ctrl+C and start again)
```

## Running

```bash
cd backend
.venv/bin/uvicorn main:app --reload --port 8000     # development (auto-reloads on .py changes)
.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000   # listen on all interfaces
```

## Extending the API — ideas

| Feature | Sketch |
|---|---|
| Search on the server | `GET /api/products?q=&category=&sort=`, filtering `PRODUCTS` in Python |
| Orders | `POST /api/orders` with cart lines; re-check prices against `PRODUCTS`; store in SQLite |
| Real users | Hash passwords (e.g. `passlib[bcrypt]`), issue JWTs, protect order endpoints |
| Admin panel | CRUD endpoints writing to a database instead of the JSON file |
| Serve images | Mount `StaticFiles` for `/img`, so the API returns absolute URLs |
